Consumo de API de Feriados

Este projeto foi desenvolvido para consumir uma API de feriados nacionais utilizando JavaScript.

 Funcionalidades
- Inserção de ano
- Consulta de feriados via API
- Exibição dos resultados em interface web

 API utilizada
https://brasilapi.com.br/api/feriados/v1/{ano}

 Tecnologias
- HTML
- CSS
- JavaScript

 Como usar
1. Abra o ficheiro index.html
2. Digite um ano
3. Clique em "Buscar"
